Paso 1

Que tipo de trabajo quieres pedir

Selecciona el servicio principal. Hemos simplificado las opciones para que encuentres antes el flujo adecuado para tu pedido.

Paso 2

Elige el tipo de impresion

Selecciona si quieres el trabajo en blanco y negro o a color.

Paso 3

Selecciona el tamano

Elige el formato para ajustar precio y acabado del pedido.

Paso 4

Cuantas copias necesitas

Indica el numero de copias para calcular el importe orientativo.

Puedes poner desde 1 hasta 5000 copias.
Paso 5

Quieres una cara o doble cara

Selecciona la configuracion de caras para el documento.

Paso 6

Elige el tipo de papel

Selecciona el acabado del papel segun el uso del documento.

Paso 7

Quieres encuadernacion

Selecciona el acabado final si tu pedido lo necesita.

Paso 8

Anade extras al pedido

Puedes marcar varios extras a la vez. Se reflejaran por separado en el precio final.

Paso 9

Sube el archivo antes del resumen

Adjunta el archivo final del pedido para poder revisar el encargo completo antes de guardarlo.

+ Sube el archivo del pedido

Puedes subir PDF, DOC, DOCX, JPG, PNG o WEBP.

Formatos permitidos: PDF, JPG, PNG | Maximo 15 MB por archivo.

Adjunta al menos un archivo antes de pasar al resumen.
